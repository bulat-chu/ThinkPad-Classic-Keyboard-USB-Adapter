## ThinkPad-Classic-Keyboard-USB-Adapter ##

The new iteration of keyboard adapter.

This one are compatible with the X60 X200 X220 series keyboards. Maybe it compatible with the X40 T60 and other series, it depends on the Power and GND pins. You can use the X220 keyboard LEDs. And it have a large number of additional GPIO PINS, what you can use them for whatever you want.
